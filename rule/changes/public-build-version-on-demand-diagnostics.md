# Public build version and on-demand admin diagnostics

- Base: `392e2f6ab360d74e2fb02458b43c7e8947c88aab`.
- Visitors see the existing application version and a UTC build timestamp at the bottom of the landing page and terminal. The id is bundled by Vite and comes from the build being served. It needs no data request. Settings and Sentry still use the existing semantic version.
- Engine Logs fetches on entry with active PIN elevation, on manual refresh and after existing log actions. Diagnostics loads when the screen is active and elevated, and refreshes on demand. The diagnostics response already includes the crash-alert mute setting, so there is no second settings fetch. Both panels offer PIN unlock when needed.
- Consumers: App navigation and the retained Diagnostics tab, Logs refresh controls, the PIN modal and the landing and terminal footers were reviewed. The existing backend admin-only checks, crash-alert and approved-bug actions, Sentry and telemetry ingestion are compatible. The landing and terminal health labels receive the engine snapshot after an explicit Logs visit instead of a background refresh. Standalone share and legal layouts are outside these two footer entry points.
- Filing compatibility: the change does not edit ingestion, dedupe, filing persistence, cache policy or the browser feed cadence. At base, the in-process fast poll checks every 15 seconds when the container has CPU, the feed client refreshes on a 12-second interval and the feed API render cache has a 6-second TTL. Actual exchange-to-browser latency and quota savings require production measurement. Resolve dashboard-specific edge rules before attributing any savings to Cloudflare.
- Impact review: the repository's impact function was applied to the baseline and updated maps using the GitHub source snapshot. The generated map pair was rebuilt for the changed source lines and dependency edges using the existing map format. The base map pair was reproduced byte-for-byte before those changes. The source runner was unavailable, so `npm run map:impact`, `npm run map:generate` and local app checks were not run. The GitHub `rules-map` check is the independent regeneration check. Static checks and the version label smoke test passed.
- Delivery: review branch and draft PR. Merge, deploy, browser verification and cloud usage measurements are separate.
