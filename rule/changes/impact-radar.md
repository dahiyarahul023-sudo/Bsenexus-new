- Starting remote main: `633215872fc8d4dde78c6c024a4a3f85c4f30b9f`.
- User objective: replace the Home Market News preview with theme-consistent, compact Impact Radar cards; put Live Radar alongside day filters; track long-running events; show only sourced event information and a neutral volatility notice before an event. No forecasts, directional expectations, targets or recommendations.
- Verified source: HomeForYou renders HomeMarketNews before watchlist/results; NewsPortal remains a separate destination. Server authMiddleware verifies identity before /api, requireAuth rejects guests; Supabase access uses a server-only service role and Firebase UID text ownership.
- Impact command: `npm run map:impact -- src/components/HomeForYou.tsx server/api/routes.ts`; inspected frontend-feed/design/navigation, market-data, user-data, storage and public-contract consumers.
- Contract: one durable event with source-backed timeline updates; per-user follows use verified UID. Date-only schedules remain dates in IST; a past scheduled date never proves a hearing or order happened. Source publication time differs from feed-check time. No fabricated cases or prices.
- Actions: radar.refresh, radar.filter, radar.open, radar.track, radar.untrack. Home owns filters/detail; account-keyed feed controller owns confirmed following and request generations. Every reader (card, count, tracking filter, detail) uses that controller. Writes report success only after durable confirmation; old-account responses are ignored.
- Changed: Home news slot, dedicated radar API/DAO/intake, shared contract, scoped styling and SQL migration. Compatible: NewsPortal/full news navigation, watchlist/results, existing alerts/Telegram, notes/payment/referral policy, global tokens and company logos. No notification dispatch is added.
- UI states: initial loading, content, empty, error/retry, retained stale content, refresh pending, following loading/error, save pending/failure, guest sign-in. Filters do not initiate competing network requests.
- Design: existing rich surface/ink/border/focus tokens, density settings, short transform/opacity motion and prefers-reduced-motion. Inline detail avoids a new modal/focus/scroll ownership contract.
- Unknowns: real browser/device behavior and hosting deployment; record actual checks below. The managed Sites environment has no control-browser capability; its skill prohibits substitute browser infrastructure.
- Storage: additive migration, RLS on all new tables, direct anon/authenticated privileges revoked, service-role-only publishing RPC. Firebase identities are not Supabase auth UUIDs. Existing schemas and policies remain untouched.
- Intake: known Indian listed-company exchange disclosures and source-reported news only; no inferred court dates, verdicts, exposure or price returns. Explicitly sourced dates and canonical case grouping are supported by admin publishing. Unrelated headlines must not be merged merely because they mention the same company.
- Release: migration rehearsal before production; code publication and database/hosting deployment are separate states. Rollback switches the Home slot back to HomeMarketNews; retain durable radar records.
- Evidence status: specified/source-traced; implementation and checks in progress. CI, browser, merge and deployment not yet verified.
